# Sounds

Drop your own clips here: `touchdown.mp3`, `field_goal.mp3`, `celebration.mp3`, and per-team
clips named `<abbr lowercase>_celebration.mp3` (for example `miss_celebration.mp3` for the Ole
Miss fight song you own a copy of). The agent plays them through the Mac's current sound output.

The `.wav` files here are synthesized placeholders (an air-horn blast and a short fanfare) made
by `make-placeholders.mjs`, so the audio path can be tested before real clips exist.
